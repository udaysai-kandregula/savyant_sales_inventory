# AI Usage Documentation

## 1. Introduction

AI tools were used as development assistants during the development of the Savyant Systems Sales and Inventory Management System.

The purpose of using AI was to improve learning, understand technical concepts, identify errors, and support development activities.

AI was used as an assistant. The project code was reviewed, executed, tested, and modified during development.

## 2. AI Tools Used

| AI Tool | Purpose |
|---|---|
| ChatGPT | Coding guidance, debugging, explanations, and documentation support |

## 3. Areas Where AI Assistance Was Used

### 3.1 Project Planning

AI assistance was used to:
- Understand the project requirements.
- Break the project into smaller development tasks.
- Plan backend modules and API development.
- Understand database relationships and business rules.

### 3.2 Backend Development

AI assistance was used for guidance and explanations related to:
- Flask application structure.
- REST API development.
- Authentication and role-based authorization.
- Customer and product management.
- Sales order processing.
- Stock management and transaction handling.
- CSV product import.
- Reporting APIs.

### 3.3 Database Development

AI assistance helped explain:
- MySQL table relationships.
- SQL queries and joins.
- Foreign keys and constraints.
- Database transactions.
- Stock-related database operations.
- Report query logic.

### 3.4 Debugging and Error Resolution

AI assistance was used to understand and troubleshoot development errors, including:
- Python import errors.
- Flask API errors.
- Database connection issues.
- SQL query errors.
- Git and command-line issues.
- API validation and response errors.

Suggested fixes were reviewed and tested before being applied.

### 3.5 Testing

AI assistance helped prepare API testing steps and test scenarios for:
- Authentication and authorization.
- Customer management.
- Product management.
- Sales order lifecycle.
- Stock movement history.
- Reports.
- CSV import validation.

Manual API requests using cURL were executed to verify application behavior.

### 3.6 Documentation

AI assistance helped prepare and organize:
- README.md
- API_DOCUMENTATION.md
- Project explanations and usage instructions.

## 4. Human Review and Responsibility

The developer was responsible for:
- Understanding the project requirements.
- Reviewing AI-generated suggestions.
- Applying and modifying code.
- Running the application.
- Executing manual API tests.
- Checking database operations.
- Managing Git commits and pushing changes.
- Reviewing project documentation.

AI-generated suggestions were not treated as automatically correct. They were checked against the actual project code and application behavior.

## 5. Limitations

AI tools can produce incorrect or incomplete suggestions.

Therefore:
- Code suggestions must be reviewed.
- Database operations must be tested.
- API responses must be verified.
- Security-related changes must be checked carefully.

## 6. Conclusion

AI tools supported the development process by providing technical explanations, debugging guidance, coding assistance, and documentation support.

The developer remains responsible for the final implementation, testing, and understanding of the project.
